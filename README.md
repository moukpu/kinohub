# 🍿 KinoHub — Сервис онлайн-просмотра и скачивания фильмов и сериалов

Современный веб-сервис для каталогизации, онлайн-просмотра и скачивания фильмов и сериалов с интеграцией **Kinopoisk Unofficial API**, видеобалансеров и торрент-трекеров.

---

## 🚀 Основные возможности

### 1. Каталог и метаданные (Kinopoisk Unofficial API)
* **Популярные новинки** и премьеры с постерами, баннерами и рейтингами;
* **Топ-250 лучших фильмов** и **Лучшие сериалы**;
* **Живой поиск** с автодополнением и мгновенным выводом карточек;
* **Фильтрация по жанрам** (боевик, комедия, фантастика, драма, триллер и др.) и сортировка;
* Карточка фильма с рейтингами (Кинопоиск & IMDb), актёрами, режиссёрами, описанием и постерами.

### 2. Онлайн-просмотр в разной озвучке и качестве
* Мульти-плеерная система с несколькими независимыми балансерами (**Alloha**, **Collaps**, **Veoveo**, **Turbo**);
* **Выбор озвучки / перевода в 1 клик**:
  * Дубляж / Лицензия
  * LostFilm
  * Кубик в Кубе
  * Red Head Sound (RHS)
  * HDRezka
  * Авторские переводы (Дмитрий «Гоблин» Пучков, Ю. Живов, А. Гаврилов, С. Визгунов и др.)
  * Оригинал с русскими/украинскими субтитрами;
* Автоматический выбор качества (**1080p Full HD**, **720p HD**, **4K**, **BDRip**).

### 3. Центр скачивания (Торренты и Magnet-ссылки)
* Парсинг актуальных релизов с трекеров по названию фильма/сериала;
* Фильтрация раздач по **качеству** (4K UHD 2160p, 1080p, 720p, SD) и по **озвучке**;
* Отображение размера файла в ГБ, количества сидов (раздающих) и личей;
* Кнопка **«⬇ Magnet»** (открытие в qBittorrent, uTorrent, TorrServer);
* Кнопка **«📋»** для мгновенного копирования magnet-ссылки в буфер обмена;
* Прямые ссылки для поиска на RuTracker, Rutor, NNM-Club и Kinozal.

### 4. Избранное и закладки
* Сохранение понравившихся фильмов и сериалов в локальное хранилище браузера (LocalStorage).

---

## 🛠 Технический стек

* **Бэкенд:** Node.js, Express, Cors, Dotenv
* **Кэширование:** In-memory TTL кэш (для экономии лимитов Kinopoisk API и мгновенного отклика)
* **Фронтенд:** Vanilla JS (ES6+), HTML5, CSS3 Glassmorphism (без тяжёлых фреймворков и сборщиков)
* **Балансеры:** Alloha, Collaps, Veoveo, Turbo, Kinobox
* **Торренты:** Rutor API parser + Magnet generator
